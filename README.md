# CareerLens

CareerLens is a career guidance dashboard designed to help students understand their current skill profile, explore career-role alignment, and identify the skills they can focus on next.

## Features

- Career-role matching dashboard
- Skill coverage visualization
- Recommended next-skill guidance
- Interactive skill progress-bar animation
- Responsive design for desktop and mobile screens
- Clear career-focused visual hierarchy
- Illustrative sample assessment data

## Product Preview

CareerLens presents a sample Data Analyst career assessment showing:

- Overall role match
- Skill coverage
- Recommended next skill
- Career development roadmap

> **Note:** All assessment scores, skill percentages, and dashboard values shown in the project are illustrative sample data and are not real user assessments.

The project includes reduced-motion handling so that animations can be minimized for users who prefer reduced motion.
